# Commercial Context

This repository consumes the Tolani Commercial Context Plane v1 from `Tolani-Corp/TolaniCorp-HQ`.

Before editing public product copy, agents and web teams must load `config/public-product-context.json`. DevBot's commercial wedge is governed request-to-reviewed-PR engineering execution, not unrestricted autonomous production access.

Public claims about autonomy, security, productivity, cost savings, reliability, or output quality require current evaluation evidence. Every CTA must map to the declared owner, downstream state, and analytics event.
